# الجريدة الشخصية 23222 — الموقع

موقع ثابت على https://jarida.gabimansour.com (GitHub Pages، فرع `main` مجلّد `docs/`).
بُني من الصفر في 1/11/2026 بدل النسخة السابقة. المحتوى نفسه، والرموز المطبوعة في أوراق الإرشاد ما زالت تعمل.

## البنية

```
data/         البيانات الخامّ بالأسماء والرموز — على الجهاز فقط ولا تُرفع أبدًا
src/          كود الصفحة: index.html و style.css و app.js
tools/        build.mjs (البناء) · publish.mjs (النشر) · check-links.mjs (فحص الروابط)
tests/e2e.mjs اختبارات في متصفّحات حقيقية، تعمل قبل كلّ نشر
docs/         ما يُنشر، ويُبنى آليًّا فلا يُعدَّل يدويًّا
```

في `docs/assets/k/` ملفّ مشفَّر لكلّ طالب، اسمه ومفتاحه مشتقّان من رمزه (PBKDF2 ثمّ AES-256-GCM).
الدخول يحتاج إلى ملفّ صاحب الرمز وحده، فلا شيء يُحمَّل قبل الضغط على «دخول».

## تعديل البيانات والنشر

عدّل الملفّ المناسب في `data/` ثمّ انشر:

| المطلوب | أين |
|---|---|
| تغيير زاوية طالب | `data.json` ← `students` ← `angle`، واحذف `"prov": true` عند التثبيت |
| إضافة مصدر | `data.json` ← `angles` ← الشعبة ← الزاوية ← `sources`، أو `sections` ← `bank` لبنك الشعبة |
| تغيير رمز | `data.json` ← `code` للطالب (4 أرقام) أو `teacherCode` للمعلّم (6 أرقام) |
| تغيير موعد أو يوم حصّة | `data.json` ← `sections` ← `dates` و`iso` و`day` و`time` |
| تعديل نموذج | `models.json` ← الشعبة ← رقم الزاوية |
| اسم الطالب بالعربية | `names-ar.json` |

```bash
npm run deploy
```

الأمر يبني ويختبر، ولا يرفع شيئًا إن فشل اختبار. للتجربة دون رفع:

```bash
node tools/publish.mjs --dry-run
```

أوامر أخرى: `npm run build` · `npm test` · `npm run links`.

البناء يتوقّف إن وجد خللًا في البيانات، مثل رمز مكرَّر أو زاوية لطالبين أو مجموع مئشار غير 30 + 70.

## لماذا لا يوجد node_modules هنا

سطح المكتب متزامن مع iCloud، وiCloud يُخلي الملفّات من الجهاز فتفشل قراءتها. لذلك تُثبَّت أداة الاختبار في
`~/.cache/jarida-23222-tools`، وأمر النشر ينسخ المستودع إلى مجلّد مؤقّت خارج iCloud ولا يحتاج إلى `.git` هنا.

## حدود الخصوصية

الموقع والمستودع عامّان. الأسماء والرموز مشفَّرة، لكنّ الرمز من 4 أرقام حماية تنظيمية لا سرّية عالية: من يملك
وقتًا ومعرفة يستطيع تجربة كلّ الرموز الممكنة. الغرض منع الفضول العابر وفهرسة الأسماء، ولا يُوضع في البيانات ما هو أشدّ حساسية.
